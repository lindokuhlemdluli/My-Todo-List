# 📝 To-Do List Manager

A simple command-line To-Do List Manager built in C++ using Code::Blocks. This project helps users create, view, update, and delete tasks efficiently from the terminal.

## 🚀 Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks between sessions (optional file-based storage)
